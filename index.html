    06

    使い方ガイド

    まずはブラウザ方式で、録音・ファイル選択から始められます。

    ブラウザ方式（推奨）

    「ブラウザで文字起こし」を選び、音声を用意して「文字起こし開始」を押します。サーバーの設定は不要です。初回だけモデルをダウンロードし、ブラウザにキャッシュします（約1GB前後、構成により増減）。2回目以降はキャッシュを使いますが、サイトデータの削除や容量不足で再取得する場合があります。

    文字起こし中、音声は端末の外に出ません。WebGPUで処理し、利用できない場合はWASM（CPU）で再試行します。PCが非力な場合やブラウザで動かない場合は、下の手順でローカルサーバーを起動し、文字起こしエンジンを「このPCのHaas-ja」に切り替えてください。

    AIノート生成は別の処理です。文字起こし本文を、このPCのサーバー経由でGeminiへ送ります。

    このPCのHaas-jaを使う

    1. 必要なものを用意

      Linux と NVIDIA GPU（CUDA）、Python 3.11 以上。Haas-ja-v1.0 は Windows と macOS では動きません。

    2. セットアップと起動

      プロジェクト直下で ./start.sh を実行します。初回だけ依存関係を導入し、.env を作ってサーバーを起動します。

    3. ページを開く

      表示された http://127.0.0.1:8000 をブラウザで開きます。初回はモデル（約1.2GB）の取得に数分かかります。

    4. エンジンを切り替えて開始

      「このPCのHaas-ja」を選び、録音または音声ファイルから文字起こしを始めます。

      サーバーの状態を見る ↑

    ノート生成を使うには Gemini APIキーが必要です。
    .env の GEMINI_API_KEY にキーを設定し、サーバーを再起動してください。詳しくはREADMEを参照してください。
