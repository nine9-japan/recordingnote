    05

    使い方ガイド

    アプリのインストール不要で、ブラウザだけで使えます。

    1. 音声を用意

      このページでそのまま録音するか、手元の音声ファイル（M4A / MP3 / WAV など）を選びます。

    2. ブラウザ内 Haas-ja で文字起こし

      「文字起こし開始」を押すと、初回だけモデル（約363 MB）を自動取得してブラウザにキャッシュし、あなたの PC 上で推論します。音声は端末の外に出ません。

    3. Gemini API で AIノート作成（任意）

      今は「Gemini APIキーを設定（任意）」にキーを入れてすぐ試せます。後からサイト側設定（gemini-note.js）に中継 API を組み込めば、利用者のキー入力も不要になります。

    2回目以降の文字起こしはブラウザのキャッシュを使うため、モデルを再ダウンロードせずに動きます。詳しくは README を参照してください。
