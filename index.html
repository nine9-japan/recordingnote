    05

    使い方ガイド

    むずかしい設定なしで、自分のPCだけで文字起こしを始められます。

    1. 起動する

      Mac / Linux は ./start.sh、Windows は start.bat を実行します。初回だけ仮想環境と .env を自動で作り、ページを開きます。

    2. Haas-ja で文字起こし

      録音または音声ファイルを選び「文字起こし開始」を押します。初回だけモデルを取得し（CPU/ONNX時は約460MB）、以後はローカルのキャッシュを使います。

    3. Gemini で AIノートを作る（任意）

      ノート生成を使うときは、フォルダ内の .env にある GEMINI_API_KEY= の後ろにキーを貼り付けて保存してください。サーバーの再起動なしで使えます。

    環境に応じて NVIDIA GPU（Linux）または CPU / ONNX（Mac・Windows・Linux）を自動で選びます。詳しい仕様やトラブル対処は README を参照してください。
